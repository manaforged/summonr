
Sessions:
  session resume [ID|NAME]    resume a session; bare resumes the last one here
  session list                list sessions
  session search TEXT         search past sessions
  session export [ID|NAME]    markdown, --digest for classify, or --json for complete audit records
  session profile [ID|NAME]   time and tokens of a session (--all [--last N])
  session diff [PATH]         changes against the base (--stat, --json, --turn N|last, --child ID)
  session children [ID|NAME]  the children a lead session started (--json)
  worktree list|prune         list summonr worktrees, or drop gone ones (--json)

Providers:
  endpoint list               list endpoints, their models, and each key state (--all, --check)
  endpoint add NAME --url URL add your own OpenAI-compatible server (--model NAME to pick one)
  endpoint add NAME --model M change the model of a server you added
  endpoint remove NAME        delete an endpoint you added
  login NAME [--key]          sign in to NAME or store its key
  login NAME --default        start on NAME when no endpoint is named (--model NAME sets its model)
  logout NAME                 forget the stored key or token

Setup:
  workflow list               list saved workflows
  module list                 list the built-in modules
  mcp list [--json]           list MCP servers, their state, and tool counts
  mcp get NAME [--json]       show one MCP server and its tools
  mcp add NAME -- CMD [ARGS]  add a stdio server (--env K=V), or --url URL (--header K=V)
  mcp remove NAME             remove an MCP server from ~/.summonr/config.toml
  panel list|check NAME       list custom panels, or run one and validate its output
  plugin install PATH         install a directory of extras
  plugin list                 list installed plugins
  plugin remove NAME          remove an installed plugin
  update                      replace this binary with the latest release
  doctor [--logs|--report]    report crashed runs; --logs lists run logs;
                              --report prints the last crash to paste into an issue

Integrations:
  acp                         serve the Agent Client Protocol on stdio
  mail                        peer mail between agent sessions: agents, send, inbox, board
  tool run NAME [JSON]        run one tool and print the result
  classify --set NAME [STATE] answer typed questions about text (below)
  cron add NAME ...           run a prompt or goal on a schedule; cron --help
  gateway telegram|webhook    start work from a Telegram chat or a web request; gateway --help
